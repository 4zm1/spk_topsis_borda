# SPK TOPSIS BORDA

## 📌 Description

SPK TOPSIS BORDA is a Decision Support System (DSS) developed using CodeIgniter 3. This system is designed to assist in decision-making processes by combining two well-known multi-criteria decision-making methods: **TOPSIS (Technique for Order Preference by Similarity to Ideal Solution)** and **BORDA Count Method**.

The system evaluates multiple alternatives based on defined criteria, calculates preference values using TOPSIS, and finalizes the ranking using the BORDA method to produce more accurate and objective decisions.

---

## 🚀 Features

* Manage criteria and alternatives
* Input and process decision data
* TOPSIS calculation (normalization, weighting, ranking)
* BORDA ranking aggregation
* Final decision results visualization
* User-friendly interface

---

## 🛠️ Technologies Used

* PHP (CodeIgniter 3)
* MySQL Database
* HTML, CSS, JavaScript
* Bootstrap (UI Framework)

---

## 📊 Method Used

### 1. TOPSIS Method

TOPSIS determines the best alternative based on the shortest distance from the ideal positive solution and the farthest distance from the ideal negative solution.

### 2. BORDA Method

BORDA is used to combine rankings from multiple results into a single final ranking, ensuring fair and balanced decision-making.

---

## 🎯 Purpose

This system aims to:

* Improve accuracy in decision-making
* Reduce subjectivity
* Provide structured and transparent results

## ⚙️ Installation

1. Clone this repository:

   ```
   git clone https://github.com/ulx-23/spk_topsis_borda.git
   ```
2. Move project to your local server (Laragon/XAMPP)
3. Import the database to MySQL
4. Configure `application/config/database.php`
5. Run the project in browser:

   ```
   http://localhost/spk_topsis_borda
   ```
